## Where the plan was changed

- Reordering asks for a second press when the board changed between the
  preview and the press. The plan's test applied it at once; the design says
  no reorder without a preview and a confirm.
- A drop is discarded, with a message, when the other person changed an axis
  while the card was being dragged.
- A drop whose second write fails is not rolled back. The matrix shows what
  the store holds and reports the failure.
- Live check P8 was added (hidden card data through REST, and a burst of
  saves), because the fallback way of syncing depends on it.
- Startup failures show an error screen with "Try again".
- Tool versions are newer than the plan named (TypeScript 7, Vite 8,
  Vitest 5), and `@types/node` was added as a dev dependency.

## Known small issues left as they are

Listed with the reviewer's reasons in the run ledger
(`.superpowers/sdd/2026-11-14-trello-matrix/progress.md`, not in git). The ones
a user could notice:

- A zoomed-in pan resets if every list is unticked and ticked again.
- If the saved view cannot be read, the matrix starts from defaults and the
  next change saves over the old view.
- Cover image that fails to load makes that card shorter.
- While a dialog shows "could not be read again", pressing Done leaves the
  matrix behind it out of date until the next update.
