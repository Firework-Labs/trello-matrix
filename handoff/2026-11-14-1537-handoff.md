## What this is

A private Trello Power-Up for the Firework Labs workspace. It shows a board's
cards on a zoomable 2D matrix so Mike and one collaborator can prioritise the
80–90 backlog items on the `67-Pass-Play-Teamwork` board. Dragging a card sets
its level on two parameters, the levels are written to Custom Fields, and a
button reorders the lists by closeness to the top-right corner.

## Decisions Mike made

- One shared matrix that both people can drag. No live cursors.
- Approach A: static page, no server, all data in Trello. He said "let's start
  with A, but keep in mind that we might have to reconsider", so all board
  access goes through one `BoardStore` interface.
- Continuous zoom. A click opens the real Trello card. Cover images show at
  close-up, with an option to turn them off.
- The better end of every axis points up or right, so top-right means "do
  first". Cost reads High to Low.
- Cards with a level on only one visible axis wait in a strip along the matrix
  edge at their known spot.
- Mike runs the live checks himself from a script; the agent machine holds no
  Trello browser logins.
- Hosting: a public repository under Firework-Labs on GitHub Pages.
